# ST7735S 彩屏接线接口文档

**屏幕型号**: 1.8 寸 ST7735S 128×160 65K 彩色 TFT-LCD（8 Pin，SPI 接口）
**主控板**: LP-MSPM0G3507 LaunchPad（MSPM0G3507）
**接口外设**: SPI1（只写）+ 4 路控制 GPIO

---

## 一、屏幕引脚定义（8 Pin）

模块为 8 脚 SPI 接口，丝印与含义如下：

| 引脚 | 名称 | 含义 |
|------|------|------|
| 1 | GND | 电源地 |
| 2 | VCC | 电源正（3.3V–5V 直流，模块自带稳压） |
| 3 | SCL | SPI 时钟线 |
| 4 | SDA | SPI 数据线（主出从入 MOSI） |
| 5 | RES | 复位接口（低电平复位） |
| 6 | DC | 数据/命令选择（低=命令，高=数据） |
| 7 | CS | 片选接口（低电平有效） |
| 8 | BLK | 背光控制（默认浮空常亮，低电平关闭背光） |

---

## 二、接线表（核心）

将屏幕接到 LaunchPad 的 **BoosterPack 排针**，对应关系如下：

| 屏幕引脚 | 功能 | → | MCU 引脚 | BoosterPack 排针 | 类型 |
|---------|------|---|---------|-----------------|------|
| GND | 电源地 | → | GND | 第 20 脚 | 电源 |
| VCC | 电源正 | → | 3V3 | 第 1 脚 | 电源 |
| SCL | SPI 时钟 | → | **PB9** | 第 7 脚 | SPI1_SCLK |
| SDA | SPI 数据 | → | **PB8** | 第 15 脚 | SPI1_PICO (MOSI) |
| RES | 复位 | → | **PB15** | 第 17 脚 | GPIO 输出 |
| DC | 数据/命令 | → | **PB16** | 第 11 脚 | GPIO 输出 |
| CS | 片选 | → | **PB17** | 第 18 脚 | GPIO 输出 |
| BLK | 背光 | → | **PB12** | 第 12 脚 | GPIO 输出 |

> ⚠️ VCC 接 **3V3**，不要接 5V 排针（第 21 脚）。模块内部虽兼容 5V，但 MCU 的 IO 为 3.3V 电平，统一 3.3V 供电最稳妥。

## 四、引脚选择说明

- **SCL / SDA** 选用 PB9 / PB8，是 LaunchPad BoosterPack 排针上 SPI1 的标准时钟/数据脚（BP 7 / BP 15），可由硬件 SPI1 外设直接驱动。
- **RES / DC / CS / BLK** 为普通推挽输出 GPIO，可换成其它空闲 PORTB 引脚，但需同步修改 SysConfig 与生成的宏。
- 本设计未使用硬件片选（CS0），而是用 **软件 GPIO（PB17）** 控制 CS，SPI 配置为 **Motorola 3 线 + 只发送（PICO only）** 模式，因此不占用 MISO / 硬件 CS 引脚。
- **避开的冲突引脚**：未使用 PA0（板载 LED1）、PA10/PA11（XDS110 串口回传）、PB2/PB3（I2C0），互不干扰。

## 五、SPI 接口参数

| 参数 | 值 |
|------|-----|
| 外设 | SPI1（控制器/主机模式） |
| 帧格式 | Motorola 3 线 |
| 通信方向 | 仅 PICO（只发送，不回读） |
| 时钟极性/相位 | Mode 0（CPOL=0, CPHA=0） |
| 帧长 | 8 bit |
| 位序 | MSB first |
| 时钟源 | BUSCLK 32 MHz ÷ 1 |
| 位速率 | 8 MHz |

---

## 六、控制引脚电平约定

| 引脚 | 上电初始值 | 工作逻辑 |
|------|-----------|---------|
| CS | 高（空闲） | 传输时拉低，结束拉高 |
| RES | 高 | 复位时拉低 ≥10 µs 再拉高 |
| DC | 低 | 发命令=低，发数据=高 |
| BLK | 低（初始化时由驱动拉高点亮） | 高=背光亮，低=背光灭 |

---

## 七、SysConfig 实例约定

代码依赖以下 SysConfig 实例名（已配置在 `empty.syscfg`）：

| 实例名 | 模块 | 生成的宏 |
|--------|------|---------|
| `SPI_0` | `/ti/driverlib/SPI`（SPI1） | `SPI_0_INST` |
| `GPIO_LCD` | `/ti/driverlib/GPIO`（PORTB） | `GPIO_LCD_PORT`、`GPIO_LCD_DC_PIN`、`GPIO_LCD_RES_PIN`、`GPIO_LCD_CS_PIN`、`GPIO_LCD_BLK_PIN` |

## 八、上手验证

1. 按上表接好 8 根线，确认 VCC 接 3V3、GND 共地。
2. 编译并下载工程（`oled_7735`）。
3. 复位运行，屏幕应先清黑屏、点亮背光，随后循环显示文本 / 色条 / 直线 / 矩形 / 圆 / 三角形 / 图像演示。

### 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 全程黑屏、无背光 | BLK 未接或接错 | 检查 BLK→PB12 |
| 有背光但白屏/雪花 | SCL/SDA/DC/CS/RES 接线错或松动 | 逐根核对接线表 |
| 显示但边缘有错位像素 | 模块存在行/列偏移 | 调整 `st7735.c` 中 `COLSTART`/`ROWSTART` |
| 红蓝颜色对调 | 面板色序为 RGB | 将初始化中 `MADCTL_BGR` 改为 `MADCTL_RGB` |
| 画面方向不对/镜像 | 旋转设置 | 调用 `ST7735_setRotation(0..3)` |
