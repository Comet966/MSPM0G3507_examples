# 感为八路灰度传感器 - 技术手册要点

来源：`感为八路灰度传感器手册_副本.pdf`（2025-04-27，感为智能科技）

## 1. 产品参数

| 参数 | 最小值 | 典型值 | 最大值 | 单位 | 条件 |
|---|---|---|---|---|---|
| 工作电压 | 4.5 | 5 | 5.5 | V | — |
| 工作电流 | 32.62 | 33 | 46.5 | mA | U=5V |
| 检测高度 | 4 | 20 | 100 | mm | U=5V |
| 响应速度 | 1.5 | 1.52 | 1.55 | ms | U=5V |
| 工作温度 | -25 | — | 85 | ℃ | — |

- 通讯方式：并行通讯 / 串行通讯 / I2C（三种可选，不互斥，硬件同时支持）
- I2C 可读取：数字量、模拟量、滞回比较器参数、错误信息等
- 官方推荐 **5V 供电**，且要与主控**共地**

## 2. 安装与接线注意事项

- **禁止与舵机/电机/喇叭等感性负载共用同一路 5V 电源**——电压尖峰会烧毁传感器
- 首次拿到设备需按"试机步骤"：先只接电源+按键 → 检测高度稳定在 ~20mm 校准 → 黑白测试 → 再上车安装
- 传感器对**安装距离敏感**，校准后不可再改变安装高度/角度，否则需重新校准
- 多个传感器共用时，安装间距需满足 `D_l ≥ 3×tan(15°)×D_h`（D_l：对管中心距，D_h：检测高度），否则光信号互相干扰
- **开漏模式跳线帽（PULL）**：主控电压低于 5V（如 3.3V）时插入，此时端口悬空，需主控内部或外置上拉电阻至 3.3V；插拔后必须重启设备才生效

## 3. 校准（每次改变安装高度都要重新校准）

1. 长按按键约 4 秒，待指示灯快速闪烁后松手 → 进入校准模式（指示灯慢闪）
2. 置于黑场，短按按键，灯快闪，记录完成后转慢闪
3. 置于白场，短按按键，灯快闪，记录完成后灯灭 → 校准完成
4. 校准结果永久保存（含记忆功能），重启不需要重新校准

## 4. 输出逻辑（数字量，所有通讯方式通用）

- 检测到**白场（浅色）→ 输出高电平**
- 检测到**黑场（深色）→ 输出低电平**
- 错误端口：正常低电平；发生错误时高电平；校准出错时输出方波，需重启复位

## 5. 三种通讯方式对比

| 方式 | 占用 I/O | 优点 | 缺点 |
|---|---|---|---|
| 并行通讯 | 8 路数字口（1 路 1 IO） | 最简单，直接 GPIO 读电平 | 占用 I/O 多 |
| 串行通讯 | 2 路（CLK + DAT，多传感器可共享 CLK） | 省 I/O，无需协议栈 | 时序需软件保证（5µs 高电平、<1ms 归零窗口） |
| I2C | 2 路（SCL + SDA，可挂 127 个设备） | 最省 I/O，可读数字量/模拟量/错误信息/固件版本，可配置地址 | 需要 I2C 外设或软件模拟，协议稍复杂 |

### 5.1 并行通讯

- 传感器最下排 1~8 号接口，每个对应一路数字量输出，主控对应 GPIO 设为**输入**（悬浮输入或上拉输入，取决于是否插 PULL 跳线帽）
- 5V 主控：GPIO 配置为悬浮输入（`INPUT`）
- 3.3V 主控：**必须插 PULL 跳线帽**开启开漏模式，GPIO 配置为**上拉输入**（`INPUT_PULLUP`），否则有烧毁主控风险

### 5.2 串行通讯（移位寄存器思路，CLK+DAT）

- CLK：主控输出，配置为推挽输出；DAT：主控输入，3.3V 主控需上拉输入（或插 PULL 跳线帽）
- 时序规则：
  1. 高电平写、低电平读——CLK 为高时传感器写入 DAT，CLK 为低时主控读取 DAT
  2. CLK 高电平必须维持 **≥ 5µs**
  3. 每个时钟间隔必须 **< 1ms**（否则内部计时器"归零"，导致只读到第 1 路数据，其余丢失）
- 一帧 8 位，读完一帧后建议 `delay_ms(1)` 完成"归零"同步，之后再读下一帧
- 理论最高速率约 1kb/s（受限于探头 1.5kHz 刷新率，超过没有意义）

### 5.3 I2C 通讯

**地址结构**（7bit 地址 + 1bit 读写）：

```
bit7   bit6  bit5  bit4  bit3 | bit2  bit1 | bit0
 1      0     0     1     1   | AD1   AD0  |  R/W
（5bit 软件地址，出厂默认 0b10011）  （2bit 硬件地址，跳线帽决定） （读写位）
```

- 出厂默认地址（AD1=AD0=0）：`0b1001110X` → 8bit 值 `0x9C/0x9E`，Arduino Wire.h 库地址（右移1位）为 **0x4E~0x4F**（取决于 AD1/AD0 跳线帽安装情况，示例中常用 `0x4f`）
- SCL/SDA 需外部或板载上拉电阻（板载 10kΩ@5V，用跳线帽启用；也可外置 1k~10kΩ 上拉）
- 通讯语法：**命令（主设备发）+ 数据（主/从设备发）**，必须先发命令再读/写数据

**常用命令符表**：

| 功能 | 命令符 | 读写 |
|---|---|---|
| 读取数字数据（8 路打包成 1 字节，bit0=OUT1…bit7=OUT8） | `0xDD` | 读 |
| 单通道读取模拟数据（第 N 路） | `0xB1`~`0xB8` | 读 |
| 连续通道读取模拟数据（一次读 8 路） | `0xB0` | 读 |
| 传输通道使能（关闭不需要的通道，默认 `0xFF` 全开） | `0xCE` | 读写 |
| 通道数据归一化使能（V3.6+，白=255/黑=0） | `0xCF` | 读写 |
| 读/写滞回比较器参数 GrayB（黑→白阈值，0→1） | `0xD0` | 读写 |
| 读/写滞回比较器参数 GrayW（白→黑阈值，1→0） | `0xD1` | 读写 |
| 软件地址配置（V3.6+ 需连发两次 `0xAD`） | `0xAD` | 写 |
| 广播重置地址（8 字节魔术串：`B8 D0 CE AA BF C6 BC BC`，发往地址 `0x00`） | — | 写 |
| ping 网络诊断（发 `0xAA`，正常返回 `0x66`） | `0xAA` | 读 |
| 读取错误信息（bit0=对管过曝，bit1=按键短路） | `0xDE` | 读 |
| 设备软件重启 | `0xC0` | 无 |
| 固件版本号查询（返回值高 4bit.低4bit = 版本号，如 `0x3E`=V3.14） | `0xC1` | 读 |

**关键使用要点**：

- 主控初始化时应循环发送 `ping`(`0xAA`) 直到收到 `0x66`，确保传感器已完成自身初始化，避免通讯时序竞争
- `ping` 命令可随时插入不打断当前命令进程（有"回滚"特性），但**写命令后不可 ping**
- 方法 3（开机默认命令即为 `0xDD`）可省略一次命令发送，效率最高，适合仅读数字量场景
- 每次修改软件地址、传输通道使能寄存器等**易失性配置**后必须在主控端保存，因为断电/重启后寄存器恢复默认值，需要在初始化阶段重新写入

## 6. 灰度测量原理简述

- 光电对管（LED 发射 + 光电三极管接收）：检测面反射光越多，三极管电流越大 → ADC 采样 → 数字信号 → 抗干扰滤波 → 滞回比较器（GrayB/GrayW 双阈值，避免抖动）→ 输出状态信号（高低电平）
- 检测高度 h 越低，灵敏度越高，但过低会因发射/接收管的几何投影导致有效面积下降，稳定性反而降低——20mm 为官方推荐典型值
- 滞回比较器采用双阈值（GrayB < GrayW）而非单阈值，可防止在临界灰度值附近来回抖动（迟滞效应）

## 7. 故障排查要点

| 现象 | 原因 | 解决 |
|---|---|---|
| 上电后错误灯常亮 | 按键端口对地短接 | 检查按键接线，排除短接后重启 |
| 错误灯无规律闪烁 | 环境光过强 | 遮挡检测面 |
| 除电源灯外无反应 | 并口接了外部线路 / PULL 装了跳线帽却未配置上拉 | 初次试机不要接外部线路；确认上拉配置 |
| 数据指示灯不亮 | 3.3V 主控未配置 GPIO 上拉 | 主控 GPIO 设为上拉输入，或移除 PULL 跳线帽（5V 主控） |
| 主控被烧毁 | 3.3V 主控直连未开漏 | 必须插 PULL 跳线帽 + 主控 GPIO 配置上拉 |
| I2C 无法通讯 | 地址错误 / 总线无上拉 / 主控上拉电压过低 | 核对地址偏移；外置 10kΩ 上拉；或用传感器板载上拉源 |

# 四路 → 八路巡线模块改造方案

现有 `Four_way_patrol_line_CCS` 工程采用**并行数字量直读**方式（GPIO 输入 + `DL_GPIO_readPins`），这是手册中最简单的通讯方式。改造为八路巡线，沿用相同架构最贴合现有代码风格：

- 新增 4 路 GPIO 输入（LineWalk_L3/L4、LineWalk_R3/R4，或按实际接线命名），与原有 4 路一致设置为输入模式
- 主循环改为读取 8 路电平并通过 UART 打印
- 若目标主控为 3.3V（MSPM0G3507 属于此类），传感器侧必须插上 **PULL 跳线帬**开启开漏模式，对应的 8 个 GPIO 需在 SysConfig 中配置为**上拉输入**，而非悬浮输入——否则数据线在传感器端呈开漏悬空状态，读到的电平不可靠

后续代码修改将通过 SysConfig MCP 工具新增 GPIO 实例，并更新 `empty.c` 主循环逻辑。
