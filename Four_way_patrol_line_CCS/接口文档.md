# 八路巡线模块 接口文档

目标器件：**MSPM0G3507**（LP-MSPM0G3507 LaunchPad）

---

## 1. GPIO 传感器输入接口

8 路传感器信号，均为**上拉输入**（3.3V 主控，传感器需插 PULL 跳线帽开启开漏模式）。

| 逻辑名称 | MCU 引脚 | BoosterPack 引脚 | SysConfig 宏（PORT） | SysConfig 宏（PIN） |
|---|---|---|---|---|
| LineWalk_L1 | PA27 | BP-8 | `LineWalk_L1_PORT` | `LineWalk_L1_PIN_27_PIN` |
| LineWalk_L2 | PA26 | BP-5 | `LineWalk_L2_PORT` | `LineWalk_L2_PIN_26_PIN` |
| LineWalk_L3 | PB15 | BP-17 | `LineWalk_L3_PORT` | `LineWalk_L3_PIN_15_PIN` |
| LineWalk_L4 | PB16 | BP-11 | `LineWalk_L4_PORT` | `LineWalk_L4_PIN_16_PIN` |
| LineWalk_R1 | PA24 | — | `LineWalk_R1_PORT` | `LineWalk_R1_PIN_24_PIN` |
| LineWalk_R2 | PA25 | BP-2 | `LineWalk_R2_PORT` | `LineWalk_R2_PIN_25_PIN` |
| LineWalk_R3 | PB17 | BP-18 | `LineWalk_R3_PORT` | `LineWalk_R3_PIN_17_PIN` |
| LineWalk_R4 | PB20 | BP-36 | `LineWalk_R4_PORT` | `LineWalk_R4_PIN_20_PIN` |

**电平逻辑**（感为传感器定义）：
- 检测到**白色/浅色** → 输出高电平 → 读值 `1`
- 检测到**黑色/深色** → 输出低电平 → 读值 `0`

**读取方式**：
```c
uint8_t val = DL_GPIO_readPins(LineWalk_L1_PORT, LineWalk_L1_PIN_27_PIN) > 0 ? 1 : 0;
```

## 2. UART 串口接口

| 参数 | 值 |
|---|---|
| 外设实例 | `UART_0_INST`（UART0） |
| TX 引脚 | PA10（BP-34，XDS110 Backchannel） |
| RX 引脚 | PA11（BP-33，XDS110 Backchannel） |
| 时钟源 | MFCLK |
| 波特率 | 115200（MFCLK 默认） |
| 数据格式 | 8N1 |
| 中断 | RX 中断已使能 |

主循环每 300 ms 输出一帧：
```
L=1234 R=5678\n
```
其中每位对应一路传感器，`1` = 白场，`0` = 黑场，顺序为 L1 L2 L3 L4 / R1 R2 R3 R4。

## 3. board.h BSP 接口

### `void board_init(void)`
初始化所有外设。调用 `SYSCFG_DL_init()` 配置 GPIO/UART/SysTick，清除并使能 UART0 RX 中断，通过串口发送启动提示。**必须在 `main()` 最开始调用，且只调用一次。**

---

### `void delay_us(unsigned long us)`
基于 SysTick 的微秒级阻塞延时。假设系统时钟为 **32 MHz**（`ticks = us × 32`）。若在 SysConfig 中修改了系统时钟频率，需同步更新 `board.c` 中的计算公式。

### `void delay_ms(unsigned long ms)`
毫秒级阻塞延时，内部循环调用 `delay_us(1000)`。

### `void delay_1us(unsigned long us)` / `void delay_1ms(unsigned long ms)`
与上述相同，为兼容性保留的别名。

---

### `void uart0_send_char(char ch)`
通过 UART0 发送单个字节。发送前轮询 `DL_UART_isBusy()` 等待就绪，**不可在中断中调用**。

### `void uart0_send_string(char* str)`
发送以 `\0` 结尾的字符串，逐字节调用 `uart0_send_char()`。

### `printf` 重定向
`board.c` 中已实现 `fputc()`，`printf` 输出自动路由至 UART0，可直接使用。

---

### UART0 RX 中断（`UART_0_INST_IRQHandler`）
接收数据存入全局缓冲区 `recv0_buff[128]`，接收完成后置位 `recv0_flag`。该 ISR 在 `board.c` 内实现，外部代码可直接读取这两个变量。

---

## 4. 其他外设（SysConfig 配置）

| 外设 | 说明 |
|---|---|
| LED1 (PA14) | 推挽输出，下拉，可用于调试指示 |
| KEY (PA18) | 上升沿中断输入，下拉，对应 LaunchPad S1 按键 |
| SysTick | 32 tick 周期，优先级 0，供 `delay_us` 使用 |
| SYSCTL | 32 MHz SYSOSC，时钟树使能 |

---

## 5. 硬件接线注意

1. 传感器供电：**5V 单独供电**，禁止与舵机/电机共用同一路 5V
2. 传感器与主控**必须共地**
3. 传感器 **PULL 跳线帽必须插上**，开启开漏模式（3.3V 主控保护）
4. PA26/PA27 在 LaunchPad 上通过 J17/J18 连接了板载光传感器，使用前需**移除 J17、J18 跳线帽**
