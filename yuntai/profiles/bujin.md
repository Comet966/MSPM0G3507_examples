# MS42C NEMA 17 兩相混合式步進電機技術規格書

MS42C 是一款高響應、大扭矩的 NEMA 17 (42mm) 步進電機，針對频繁啟停、快速換向等動態控制場景（如自平衡小車、ROS 移動機器人、3D 列印機）進行了繞組優化，常與磁編碼器搭配作閉環控制。

---

## 一、 核心電氣與機械參數

| 參數項目 | 規格數據 | 備註說明 |
| :--- | :--- | :--- |
| **電機尺寸** | 42 mm × 42 mm × 42 mm | 標準 42 電機（不含輸出軸） |
| **電機類型** | 兩相混合式 (2-Phase Hybrid) | 步距角 1.8°（整步一圈 200 脈衝） |
| **額定電流** | 1.5A ~ 1.68A | 驅動器限流建議設定在 1.5A 左右 |
| **靜態扭矩** | 0.36 N·m (約 3.6 kg·cm) | 高動態負載抗性 |
| **相電阻** | 1.65 Ω | 低內阻，減少高頻換向發熱 |
| **相電感** | 3.2 mH | - |
| **轉動慣量** | 50 g·cm² | 低慣量，啟停響應極快 |
| **輸出軸徑** | Φ 5mm (D型軸) | 便於鎖緊聯軸器或同步輪，防止打滑 |
| **本體重量** | 約 283 g | - |

## 二、 接線定義 (電機末端 PH2.0-6P 接口)

電機內部兩相繞組對應的線色如下：

| 繞組通道 | 接線顏色 | 驅動器接口對應 |
| :---: | :---: | :---: |
| **A+** | 黑色 | 電機 A+ / A1 |
| **A-** | 綠色 | 電機 A- / A2 |
| **B+** | 紅色 | 電機 B+ / B1 |
| **B-** | 藍色 | 電機 B- / B2 |

> 💡 **調相技巧**：
> 若運行方向與控制方向相反，只需將 **A+/A-** 對調（或 **B+/B-** 對調），即可在硬體層面實現反向。

## 三、 開發與驅動配置建議

### 1. 供電電壓
雖然步進電機本身無固定額定電壓，但為了確保高速下的動態扭矩輸出，推薦驅動電壓為 **12V ~ 24V DC**。

### 2. 開環驅動配置 (如 A4988 / TMC2209 / TB6600)
* **電流限制 (Current Limit)**：驅動器 Vref/電流撥碼需限制在 **1.5A** 左右，避免長時間運行導致電機過熱。
* **細分設置**：平衡小車或精準定位推薦使用 **16細分 (1/16 Step)** 或以上，以減少低速共振與噪聲。

### 3. 閉環升級 (抗丟步方案)
* 針對平衡小車等強換相波動場景，建議在電機後端加裝磁編碼器（如 **MKS SERVO42C** 或 **A4954 方案**），組成閉環步進一體機，可徹底避免極限動態下的丟步問題。
