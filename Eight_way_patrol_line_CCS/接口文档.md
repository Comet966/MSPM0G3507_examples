# 八路巡线模块接口文档

目标器件：**MSPM0G3507**（LP-MSPM0G3507 LaunchPad）

---

## 1. 硬件接线

### 1.1 感为八路灰度传感器（串行模式）

> **注意：本项目使用串行通讯模式（CLK + DAT），而非并行或 I2C 模式。**

| 传感器引脚 | 信号名 | MCU 引脚 | BoosterPack 引脚 | 说明 |
|-----------|--------|---------|-----------------|------|
| CLK       | 时钟   | PA13    | BP-36（J3）     | MCU → 传感器，推挽输出，空闲低电平 |
| DAT       | 数据   | PA12    | BP-35（J3）     | 传感器 → MCU，上拉输入（开漏模式） |
| +5V       | 电源   | —       | 独立 5V 供电    | **必须与电机/舵机电源分开** |
| GND       | 地     | GND     | 任意 GND 引脚   | 与主控共地 |

**传感器跳线帽设置：**
- **PULL 跳线帽必须插上** — 开启开漏模式，保护 3.3 V 主控 GPIO
- 校准后不可改变安装高度/角度，推荐检测高度 20 mm

### 1.2 SSD1306 OLED 显示屏（I2C 模式）

| OLED 引脚 | 信号名 | MCU 引脚 | BoosterPack 引脚 | 说明 |
|----------|--------|---------|-----------------|------|
| GND      | 地     | GND     | 任意 GND 引脚   | — |
| VCC      | 电源   | 3.3V    | 3.3V 引脚       | — |
| SCL      | I2C 时钟 | PB2  | BP-9            | I2C1 SCL，400 kHz |
| SDA      | I2C 数据 | PB3  | BP-10           | I2C1 SDA，400 kHz |

OLED I2C 地址：`0x3C`（7 位，D/C# 引脚接 GND）

### 1.3 UART 调试串口（XDS110 Backchannel）

| 信号 | MCU 引脚 | 说明 |
|------|---------|------|
| TX   | PA10    | 连接至板载 XDS110，无需外部接线 |
| RX   | PA11    | 连接至板载 XDS110，无需外部接线 |

波特率：**115200**，格式：8N1

## 3. 串行通讯协议（CLK + DAT）

### 3.1 时序规则

```
CLK:  _____┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐____________
           │  │  │  │  │  │  │  │  │  │  │  │  │  │  │  │
DAT:  ─────┤CH1├─┤CH2├─┤CH3├─┤CH4├─┤CH5├─┤CH6├─┤CH7├─┤CH8├────────────
           └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘
           ↑读取时机（CLK 高电平期间 DAT 有效）
```

| 参数 | 值 | 说明 |
|------|-----|------|
| CLK 高电平宽度 | ≥ 5 µs | 传感器驱动 DAT 所需建立时间 |
| CLK 低电平宽度 | ≥ 5 µs，< 1 ms | 超过 1 ms 触发内部计时器复位 |
| 帧间隔 | ≥ 1 ms | CLK 保持低电平，复位传感器内部计数器 |
| 理论最大速率 | ~1 kbps | 受限于传感器 1.5 kHz 刷新率 |

**关键限制：** 相邻两个时钟沿之间的间隔必须小于 1 ms，否则传感器内部计数器复位，后续位均读取第 1 路数据导致帧错误。读完 8 位后主动延时 ≥ 1 ms 可安全复位计数器，确保下一帧从第 1 路开始。

### 3.2 数据格式

- 每帧 8 位，LSB（bit0）= CH1，MSB（bit7）= CH8
- `1` = 检测到白色/浅色；`0` = 检测到黑色/深色

## 4. 软件接口

### 4.1 linewalk 驱动接口（`linewalk.h` / `linewalk.c`）

#### `void LineWalk_init(void)`

初始化传感器串行接口，将 CLK 输出拉低（空闲状态）。

**调用时机：** 在 `board_init()` 之后、主循环之前调用一次。

#### `uint8_t LineWalk_read(void)`

读取一帧 8 路传感器数据。

**返回值：** 8 位无符号整数，bit0 = CH1，bit7 = CH8。`1` 表示白场，`0` 表示黑场。

**阻塞时间：** 约 1.1 ms（8 个时钟周期 + 1 ms 帧间隔）。

**示例：**
```c
uint8_t val = LineWalk_read();

// 判断第 1 路（最左侧）是否在黑线上
if ((val & 0x01) == 0) {
    // CH1 检测到黑线
}

// 获取所有 8 路状态
for (int i = 0; i < 8; i++) {
    uint8_t ch = (val >> i) & 1;  // 1=白, 0=黑
}
```

### 4.2 OLED 显示接口（`oled.h` / `oled.c`）

复用自 `IIC_oled` 项目，接口完整说明见下表：

| 函数 | 说明 |
|------|------|
| `OLED_init()` | 初始化 I2C 和 SSD1306，清空帧缓冲 |
| `OLED_clear()` | 清空帧缓冲，标记所有页为脏页 |
| `OLED_display()` | 将脏页刷新到屏幕（仅传输变化的页） |
| `OLED_setCursor(col, page)` | 设置文字光标，col: 0–15，page: 0–7 |
| `OLED_writeString(str)` | 输出字符串（8×8 像素字体） |
| `OLED_printf(fmt, ...)` | 格式化输出，内部缓冲区 64 字节 |
| `OLED_setPixel(x, y, on)` | 设置单个像素 |
| `OLED_drawLine/Rect/Circle(...)` | 基本图形绘制（写帧缓冲，需调用 display() 刷新） |

**OLED 屏幕布局（本项目运行时显示）：**

```
行 0（page 0）: "8-Way LineSensor"
行 1（page 1）: （空）
行 2（page 2）: "CH 1 2 3 4 5 6 7 8"
行 3（page 3）: "   O X O O X X O X "   O=白场  X=黑场
行 4（page 4）: （空）
行 5（page 5）: "Val: 0xAB  "
```

| 函数 | 说明 |
|------|------|

| 外设 | 实例名 | 配置 |
|------|--------|------|
| SYSCTL | — | SYSOSC 32 MHz，时钟树使能，MFCLK 4 MHz 使能 |

| GPIO | `LINEWALK_DAT` | PA12，输入，上拉 |

## 6. 接线注意事项

1. **传感器电源独立供电：** 传感器工作电压 5V，禁止与电机、舵机、喇叭共用同一路 5V，感性负载的电压尖峰会损坏传感器。

2. **必须共地：** 传感器 GND 与主控 GND 必须相连，否则串行通讯电平参考不一致。

3. **PULL 跳线帽必须插上：** 3.3 V 主控（MSPM0G3507）使用 3.3 V GPIO，传感器 DAT 为开漏输出，需要跳线帽开启内部上拉，否则 DAT 无法被拉低，且可能损坏主控 GPIO。

4. **CLK 电平问题：** PA13 输出 3.3 V，而传感器工作在 5 V（VIH 典型约 3.5 V），实测可正常工作。如遇 CLK 识别异常，可在 PA13 与 5 V 之间加 10 kΩ 上拉电阻，或增加电平转换器。

5. **OLED 上拉：** SSD1306 模块通常板载 I2C 上拉电阻，直接连接 PB2/PB3 即可，无需外部上拉。

6. **调试串口：** PA10/PA11 通过 LaunchPad 板载 XDS110 连接至 USB，无需额外接线，直接在 PC 端打开串口终端（115200 baud）即可接收数据。
