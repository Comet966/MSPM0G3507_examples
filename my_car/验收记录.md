## 使用说明

- 工作流：**我实现一个模块 → 你按本文件上板测试 → 通过后我做下一个**（遵循 yaoqiu.md）。
- 每阶段两类验收项：
  - **编译类**（无需硬件）：在 CCS 里 build 通过即可，现在就能验收。
  - **上板类**（需连接板子）：烧录后观察现象/串口输出。

## 上板验收前提（每次上板前先做）

1. 用 USB 连接板子的 **XDS110 调试器**（板载调试器，或外接 XDS110 接到 SWD：PA19=SWDIO / PA20=SWCLK）。
2. 板子上电。
3. 串口工具设置：**115200 波特率，8 数据位，无校验，1 停止位（8N1）**。端口是 XDS110 的虚拟串口（背通道 UART0 = PA10 TX / PA11 RX）。
4. 我这边会先用 `getConnectedDevices` / `listSerialPorts` 确认能看到设备，再烧录。

> ⚠️ 当前状态（2026-07-02）：**未检测到 XDS110 与 TI 串口**，即板子未连接。上板类验收需先接好板子。

## Phase 1 — System + Timer + Uart（上板验收）　✅

- **验收内容**：SysTick 时基（millis/micros/delay）、200Hz 硬件定时器（软件分频出 100/10Hz）、UART0 串口输出。
- **验收方法**：接好板子上电（115200 8N1）→ 我烧录运行并连接串口 → 观察串口输出与板载 LED。
- **通过标准**（全部满足）：
  1. 串口出现横幅 `my_car Phase1: System+Timer+Uart up. MCLK=80MHz.`
  2. 每秒打印 `t_ms=... / tick200=... / ---`，`t_ms` 每秒 +≈1000，`tick200` 每秒 +≈200。
  3. 板载 LED2 绿灯（PB27）5Hz 闪烁（10Hz 翻转）。
- **状态**：✅ 已通过（2026-07-02 上板实测）。
- **实测数据**：30 秒内 tick200 从 201→6199 = **199.9 Hz**（误差 <0.05%）；`t_ms` 每秒 +1000 准确。SysTick、200Hz 节拍、UART0 打印全部正常。
- **备注**：
  - 相比参考代码 4 个独立定时器，这里只用 **1 个 200Hz 定时器（TIMG7）+ 软件分频**，并用内核 **SysTick** 做 1ms 时基与 `duty_1000hz`，省下 TIMG8/TIMG12 给后续 PWM/步进/蜂鸣器。
  - 烧录后串口缓冲里会先出现上一版残留的 `tick NNN`，横幅之后才是本阶段输出。

## Phase 2 — 蜂鸣器 + 按键（上板验收）　✅

- **验收内容**：TIMG6 驱动的蜂鸣器（声光反馈）+ PB21（S2）按键消抖，短按启停切换 `CarStartFlag`，状态 LED 指示运行态。
- **验收方法**（纯物理，脱离调试器）：
  1. 按开发板 **RESET/NRST 复位键**（或断电重上电），让已烧录的 Phase 2 固件独立运行。
  2. 观察板载状态 LED 与蜂鸣器，按 S2（PB21）测试。
- **通过标准**：
  | 现象 | 标准 |
  |------|------|
  | 上电/复位后 | 状态 LED 灭（初始 CarStartFlag=0） |
  | 短按 S2 | 蜂鸣一声 + LED 翻转（灭↔亮） |
  | 连续短按 | 每次都翻转，一按一声 |
  | 长按 >0.5s | 蜂鸣两声 + LED 灭（Phase 6 会补完 lap/reset 语义） |
  | 快速轻点 | 不重复触发（~20ms 消抖窗口） |
- **状态**：✅ 已通过（2026-07-02 物理验收：按 S2 → 蜂鸣一声 + LED 翻转，启停切换正常）。
- **备注**：
  - 短按判据 `SHORT_MIN_SAMPLES=4`（~20ms @200Hz 消抖），长按 `LONG_SAMPLES=100`（~500ms）；动作在**按键释放**时触发。
  - 蜂鸣器用 TIMG6 PWM：`buzzer_on()`=启动计数器，`buzzer_off()`=停计数器 + 拉低引脚（CC=0 静音不可靠，必须双管齐下）。
  - 本阶段串口/调试器观测受 MCP 工具日志缓冲回放影响（一直回放 Phase 1 残留），故采用纯物理验收，结果可靠。

## Phase 3 — TB6612 双轮 PWM（开环）　🟡

- **验收内容**：TIMA0 双通道 20kHz PWM（PB8/PB9）+ TB6612 方向控制（AIN/BIN/STBY），两轮能按指令正反转、调速，开环无编码器。
- **接线表**（TB6612 ↔ MSPM0G3507）：
  | TB6612 | MCU 引脚 | 说明 |
  |--------|---------|------|
  | PWMA | PB8 | 左电机 PWM（TIMA0.CCP0） |
  | AIN1 / AIN2 | PB0 / PB1 | 左电机方向 |
  | PWMB | PB9 | 右电机 PWM（TIMA0.CCP1） |
  | BIN1 / BIN2 | PB4 / PB5 | 右电机方向 |
  | STBY | PB6 | 使能（高=工作，低=待机） |
  | VM | 电池正（7.4~12V） | 电机电源 |
  | VCC | 3.3V | 逻辑电源 |
  | GND | 共地 | **必须与 MCU 共地** |
  | AO1/AO2 | 左 MG513 两线 | 电机输出 |
  | BO1/BO2 | 右 MG513 两线 | 电机输出 |
- **验收方法**（建议**车轮悬空**，避免乱跑）：
  1. 按上表接好 TB6612、电机、电池、共地。**先确认共地和电源电压再上电**。
  2. 复位板子让固件运行。此时两轮应静止（STBY 已使能但占空比 0）。
  3. 按 **S2**，进入自检序列。固件每 1.5 秒切一步，串口打印当前步：
     - `FWD  (both +)` → 两轮**同向前进**
     - `STOP` → 停
     - `REV  (both -)` → 两轮**同向后退**
     - `STOP` → 停
     - `LEFT fwd only` → **仅左轮**前进
     - `RIGHT fwd only` → **仅右轮**前进
     - 循环
  4. 再按 S2 停止，两轮立即停转。
- **通过标准**：
  1. FWD 步两轮都朝**车前进方向**转（若某轮反了，说明该电机两线接反或 AIN/BIN 定义需调）。
  2. REV 步两轮都反向转。
  3. LEFT/RIGHT 步只有对应一侧转，另一侧不动 → 左右通道独立、无串扰。
  4. 占空比 30% 时转速明显低于满速（说明调速有效）。
  5. 停止时两轮立即静止。
- **状态**：✅ 已通过（2026-07-02 上板物理验收：复位后停止、按 S2 自检序列正反转/单轮均正确）。
- **关键调试记录（PWM 极性根因）**：初次上板"复位后两轮就全速转"，翻转占空比符号无效。查 SDK `peripherals/TIMER.md` 定位到**两个独立事实**：
  1. 占空比映射是 `duty% = CC / period`（**CC = duty 直接**），初版 `CC = 1000 − duty` 是反的。
  2. 文档 CRITICAL：边沿对齐模式下 **`CC = 0` 不能可靠拉低 PWM 脚**，引脚会锁存高电平。故复位时 `PWM_SetDuty(0,0)` → CC=0 → PWM 脚卡高 + 方向脚已置位 → TB6612 全速驱动。
  - **修复**：① 占空比用 `CC = duty`；② "停"不依赖 PWM 脚，命令为 0 时把方向脚**双低（coast 滑行）**，按 TB6612 真值表直接停，与 PWM 锁存无关。教训：极性/停止行为以 SDK 文档为准，勿靠翻符号试错。
- **备注 / 排错**：
  - **某轮转向反了**：把该电机的两根输出线（AO1↔AO2 或 BO1↔BO2）对调即可，或告诉我在代码里翻转该侧 AIN/BIN 逻辑。
  - **完全不转**：查 STBY 是否为高（PB6）、VM 电源、共地；万用表量 PWMA/PWMB 有无 ~20kHz 方波。
  - **两轮都动但方向定义与"前进"相反**：整体接反，把左右两电机线都对调，或代码里把 TEST_DUTY 取负——接线阶段确认后我统一在 headfile 里定义方向极性。
  - PWM=20kHz（超声频段，人耳基本听不到啸叫）；占空比 `CC = duty` 直接映射；停止靠方向脚 coast，不靠 CC=0。
  - 本阶段**开环无速度反馈**，两轮转速可能略有差异属正常，Phase 4 加编码器 + PID 后闭环校正。
