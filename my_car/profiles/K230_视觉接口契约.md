# K230 ↔ MSPM0G3507 视觉接口契约

> 交给 K230 端 agent 的**接口要求文档**。本文件定义 K230（视觉协处理器）与 MSPM0G3507（主控/小车）之间的 UART 通信协议。
> 双方各自独立实现、独立调试，只要都遵守本契约即可对接。
>
> 赛题背景：北邮 2026 电赛"巡迹作业一体平台"。**行驶与对靶必须能不依赖视觉完成**，K230 仅作**辅助定位**（发挥项：动态跟随、同步绘制）。因此 K230 掉线/无数据时，主控会回退到几何开环瞄准，K230 端无需关心兜底逻辑，只需在识别到目标时持续上报，未识别时上报 `found=0`。

---

## 1. 物理层

| 项目 | 值 |
|------|-----|
| 接口 | UART（TTL 3.3V，**严禁 5V** 直连 MSPM0） |
| 波特率 | **115200** |
| 数据格式 | 8 数据位，无校验，1 停止位（8N1） |
| 主控引脚 | K230_TX → MCU PB15(RX)，K230_RX ← MCU PB16(TX)（MCU 侧 UART2） |
| 共地 | **必须共地** |
| 流控 | 无 |

> 接线交叉：K230 的 TX 接 MCU 的 RX，K230 的 RX 接 MCU 的 TX。

---

## 2. 主数据流：K230 → MSPM0（目标信息帧）

K230 **持续、周期性**发送目标信息帧，建议 **20~50 Hz**（与你的视觉帧率一致即可，不要超过 100Hz 以免拥塞）。

### 2.1 帧格式（固定 9 字节）

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | 帧头1 | u8 | `0xAA` |
| 1 | 帧头2 | u8 | `0x55` |
| 2 | found | u8 | `1`=当前识别到靶心，`0`=未识别（未识别时 dx/dy/dist 填 0） |
| 3~4 | dx | **int16, 小端** | 靶心相对**画面中心**的 X 偏移（像素），**右为正** |
| 5~6 | dy | **int16, 小端** | 靶心相对**画面中心**的 Y 偏移（像素），**下为正** |
| 7~8 | dist | **int16, 小端** | 估计距离（cm），无法估计填 `0`（可选字段） |
| 9 | checksum | u8 | 对**偏移 2~8 共 7 个字节**做异或（XOR）校验 |

> 注意：checksum 是第 10 个字节，故整帧共 **10 字节**（帧头2 + 载荷7 + 校验1）。
>
> **坐标定义（务必对齐）**：以画面几何中心为原点 (0,0)。靶心在画面偏右 → dx>0；靶心在画面偏下 → dy>0。主控据此驱动云台：dx>0 时云台向右转（pan+），dy>0 时云台向下转（tilt+）。若你的相机安装方向导致极性相反，请在 K230 端取反后再发，保证"靶心偏右→dx正"这一语义。

### 2.2 校验算法（C 参考）

```c
uint8_t cksum = 0;
for (int i = 2; i <= 8; i++)   // 偏移 2..8，共 7 字节（found, dx_l, dx_h, dy_l, dy_h, dist_l, dist_h）
    cksum ^= frame[i];
frame[9] = cksum;
```

### 2.3 int16 小端打包（C 参考）

```c
int16_t dx = ...;             // 例如 -37
frame[3] = (uint8_t)(dx & 0xFF);        // 低字节
frame[4] = (uint8_t)((dx >> 8) & 0xFF); // 高字节
```

### 2.4 完整发送示例（C 伪码，K230 端）

```c
void send_target(uint8_t found, int16_t dx, int16_t dy, int16_t dist)
{
    uint8_t f[10];
    f[0] = 0xAA; f[1] = 0x55;
    f[2] = found;
    f[3] = dx   & 0xFF;  f[4] = (dx   >> 8) & 0xFF;
    f[5] = dy   & 0xFF;  f[6] = (dy   >> 8) & 0xFF;
    f[7] = dist & 0xFF;  f[8] = (dist >> 8) & 0xFF;
    uint8_t c = 0;
    for (int i = 2; i <= 8; i++) c ^= f[i];
    f[9] = c;
    uart_write(f, 10);
}
```

### 2.5 主控端解析状态机（MSPM0 侧已按此实现，供你对齐理解）

主控用状态机逐字节收：等 `0xAA` → 等 `0x55` → 收 7 字节载荷 → 收校验并比对。校验通过才更新 `Vision_t`，并记录接收时间戳用于**掉线检测**（超过约 200ms 无有效帧 → 视为丢失，found 视作 0，回退几何瞄准）。所以 K230 端**即使未识别也要持续发 found=0 的心跳帧**，否则主控无法区分"没识别到"和"K230 挂了"。

## 3. 可选反向流：MSPM0 → K230（模式指令，用于分模块调试）

主控可选地下发当前模式，便于 K230 端切换处理逻辑或独立自检。**K230 端可先忽略此流，不影响主数据流**。

### 3.1 帧格式（固定 3 字节）

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | 帧头 | u8 | `0xBB` |
| 1 | mode | u8 | `0`=待机 `1`=瞄准（定点） `2`=绘制（动态跟随/同步绘制） |
| 2 | checksum | u8 | = mode（单字节异或，即 mode 本身） |

## 4. 契约要点小结（K230 端 checklist）

- [ ] UART 115200/8N1，TX/RX 交叉接 MCU PB15/PB16，共地，3.3V 电平。
- [ ] 持续发目标帧 20~50Hz，**未识别也发 found=0 心跳**。
- [ ] 帧 = `AA 55 | found | dx(LE16) | dy(LE16) | dist(LE16) | xor(载荷7字节)`，共 10 字节。
- [ ] 坐标语义：画面中心为原点，靶心偏右 dx>0、偏下 dy>0；相机方向不符则在 K230 端取反。
- [ ] dist 无法估计填 0；不影响主控（主控可用几何距离兜底）。
- [ ] （可选）接收 `0xBB | mode | mode` 模式指令。

---

## 5. 联调建议

1. **K230 单独自检**：先用 PC 串口助手（115200 8N1）接 K230 TX，确认帧格式、帧率、坐标极性正确（把靶标左右上下移动，观察 dx/dy 符号）。
2. **对接主控**：主控侧我会提供一个调试模式，把收到的 `found/dx/dy/dist` 通过 UART0 背通道打印出来，双方比对同一目标位置数值是否一致。
3. **极性验证**：靶心在画面右侧时确认 dx 为正、云台向右；不一致则调整 K230 端取反，不要改主控。
4. **掉线测试**：拔掉 K230 TX，确认主控在 ~200ms 后回退到几何开环瞄准仍能对靶（基础项得分不依赖视觉）。
