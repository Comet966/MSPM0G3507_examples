# 25E题底盘国一开源 — 代码解析与接线文档

## 一、能否用 CCS 打开？

**不能直接打开。** 本项目只有 Keil MDK 工程文件（`keil/ncontroller.uvprojx`），**没有** CCS 所需的 `.project` / `.cproject` 文件。

如要迁移到 CCS，需要：
1. 在 CCS 中新建一个 Empty MSPM0G3507 工程
2. 将 `ncontroller.syscfg` 导入（CCS 内置 SysConfig 插件可直接识别）
3. 将所有 `.c` / `.h` 文件和 `source/` 目录添加进工程，按如下 Include Path 配置：
   ```
   source/third_party/CMSIS/Core/Include
   source/
   ./
   user/
   Algorithm/
   dsplib/
   HardwareDriver/
   FunctionalModule/
   ApplicationLayer/
   ```
4. 链接 `dsplib/` 中的 CMSIS-DSP 预编译库（对应 `arm_math.h`）

**推荐做法**：直接用 **Keil MDK**，打开 `keil/ncontroller.uvprojx` 即可编译烧录，零配置。

## 三、整体架构

固件分四层，依赖关系单向向下：

```
ApplicationLayer        ← 任务状态机（赛题逻辑）
    ↓
FunctionalModule        ← 功能模块（传感器 / 电机 / 外设）
    ↓
HardwareDriver          ← 硬件驱动（DriverLib 薄封装）
    ↓
ti_msp_dl_config        ← SysConfig 自动生成（禁止手动修改）
```

全局唯一数据载体：`Car_t Car`（`main.c`），通过指针聚合所有子系统对象。所有子系统对象以 `static` 局部变量方式在各自 `Init()` 函数中分配，通过双指针传出。

### 调度机制

系统采用**纯中断驱动**架构，`while(1)` 主循环仅刷新 OLED，所有控制逻辑均在定时器 ISR 中执行：

| 频率 | 定时器实例 | 执行内容 |
|------|-----------|---------|
| 1000 Hz | TIMERG6 | 保留未用 |
| **200 Hz** | TIMERG7 | 按键扫描 → 灰度采样 → 编码器更新 → 任务状态机 → 电机PID → PWM输出 |
| 100 Hz | TIMERG8 | 未启动时电机停止保护 |
| 10 Hz | TIMERA1 | 蜂鸣器节拍更新 |

所有控制闭环运行在 200 Hz，采样周期 5 ms。

## 四、核心算法详解

### 4.1 灰度循迹

8路灰度传感器通过 **3位GPIO多路复用器** 轮询共用单路 ADC12，每路采样4次取后3次均值去抖。

归一化方式：
```
normalized = (raw - black_cal) × (4096 / (white_cal - black_cal))
```

白/黑校准值硬编码在 `GraySensorInit()`，换场地必须重新标定（见第六节）。

转向角计算采用**加权质心法**：
```c
const float weights[8] = {3.0, 1.5, 0.5, 0.10, -0.10, -0.5, -1.5, -3.0};
// 正值→右偏，负值→左偏
turnAngle = (weightedSum / totalWeight) × 10.0f;
```

### 4.2 直角检测与过弯状态机

`Task.c` 中四个状态的完整流转：

| 状态值 | 含义 | 退出条件 |
|--------|------|---------|
| 0 | 正常循迹 | bit0\~bit2 全暗 → 进入1 |
| 1 | 检测到直角，等待越过车头 | 里程 > `CAR_LENGTH`（0.1 m）→ 进入2 |
| 2 | 强制左转中 | 行进 > `Turn_LENGTH`（30 cm）且检测到黑线 → 进入0；否则 `Deltayaw = Turn_Speed` |
| 3 | 最后一圈返回停止点 | 里程 > 记录的起始段长度 → 停车 |

每完成4个直角（一整圈）`CircleCount--`，配合蜂鸣器报圈。末圈记录第一条直道长度，在该里程处精确停车。

### 4.3 电机差速控制（双环PID）

```
自转PID(Deltayaw → 0) → ExpectDifferentia
左轮设定 = AverageSpeed - ExpectDifferentia
右轮设定 = AverageSpeed + ExpectDifferentia
各轮PID(encoder_velocity, 轮设定) → PWM占空比
```

速度按直道位置动态分段：

| RightAngleCount | AverageSpeed |
|-----------------|-------------|
| 2（弯道前后） | 30 |
| 0 或 4（直道）| 35 |
| 1 或 3（其他）| 40 |

### 4.4 PID参数

| 参数组 | Kp | Ki | Kd | 输出限幅 |
|--------|----|----|-----|---------|
| 轮速PID | 10.0 | 0.8 | 5.0 | ±1000 |
| 自转PID | 0.8 | 0.0 | 0.15 | ±200 |

## 五、完整引脚接线表

### 5.1 电机驱动

#### PWM 输出（TIMA0，4路，约 9.99 kHz）

| 通道 | MCU 引脚 | 对应电机 |
|------|---------|---------|
| CH0 | **PA8** | 左前电机 PWM |
| CH1 | **PA9** | 右前电机 PWM |
| CH2 | **PA7** | 右后电机 PWM |
| CH3 | **PB2** | 左后电机 PWM |

> PWM 分频 ÷8，计数值 1001，频率 = 80M ÷ 8 ÷ 1001 ≈ **9.99 kHz**

#### 方向控制 GPIO（PORTB，输出，内部下拉）

| 引脚 | 功能 |
|------|------|
| **PB9** | 左前电机方向 |
| **PB16** | 左后电机方向 |
| **PB14** | 右前电机方向 |
| **PB15** | 右后电机方向 |

逻辑：Output > 0 时，左前/右前清零引脚，左后/右后置位引脚（正转）。若转向反需翻转对应逻辑。

---

### 5.2 编码器（外部中断计数，仅左右各一路）

#### 编码器1（左侧）

| 信号 | MCU 引脚 |
|------|---------|
| A 相（方向判断） | **PB8** |
| B 相（中断计数） | **PB3**（上升沿，优先级1） |

#### 编码器2（右侧）

| 信号 | MCU 引脚 |
|------|---------|
| A 相（方向判断） | **PA12** |
| B 相（中断计数） | **PA13**（上升沿，优先级1） |

> 左前/左后共用 Encoder1，右前/右后共用 Encoder2。

---

### 5.3 灰度传感器阵列（8路，MUX轮询 + 单路ADC）

使用 **8选1 模拟多路复用器**（如 CD4051/74HC4051）。

#### 地址选择 GPIO（输出）

| MCU 引脚 | MUX 地址线 | 选通通道 |
|---------|-----------|---------|
| **PB24** | SEL_A（bit0） | — |
| **PB19** | SEL_B（bit1） | — |
| **PA1** | SEL_C（bit2） | — |

通道对应关系：000=bit0, 001=bit1, ..., 111=bit7

#### ADC 输入

| 引脚 | 功能 |
|------|------|
| **PB20** | ADC0 CH6，接 MUX 公共输出（Z端） |

#### 传感器物理位置（车头朝前）

```
←左                              右→
bit0  bit1  bit2  bit3  bit4  bit5  bit6  bit7
 权+3  +1.5  +0.5  +0.1  -0.1  -0.5  -1.5   -3
```

## 六、关键参数速查与修改位置

### 调参（`user/headfile.h`）

```c
// 轮速 PID
#define BrushMotor_PID_KP    10.0f
#define BrushMotor_PID_KI     0.8f
#define BrushMotor_PID_KD     5.0f

// 差速（转向）PID
#define SelfTurn_PID_KP       0.8f

#define SelfTurn_PID_KD       0.15f

// 机械参数
#define EncoderLines         260.0f   // 编码器线数/转

// 赛道参数

#define Turn_LENGTH           30.0f   // 过弯搜线距离 cm

```

### 灰度传感器校准（`FunctionalModule/GraySensor.c` → `GraySensorInit()`）

修改 `calibrated_white[8]` 和 `calibrated_black[8]` 两个数组，数值为 12 位 ADC 原始值（0~4095）。白色值应高于黑色值。

## 七、调试方法

- `uart_printf(float)` 通过 UART0（PA10，115200 baud）发送浮点数，用串口助手接收
- `Task.c` 和 `GraySensor.c` 中有大量被注释的 `uart_printf` 调用，按需取消注释观测信号
- `uart0_send_char(0x01)` 标记直角检测事件，可在上位机观察检测时序
- 比赛时确认所有调试输出已注释，避免 200 Hz 中断内串口阻塞影响控制周期
